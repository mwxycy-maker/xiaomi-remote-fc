# 横握小米遥控器玩 FC 游戏

一个可离线打开的本机 FC 游戏页：将蓝牙遥控器横握，左侧方向环当方向键，右侧上方 TV 键当 A，下方菜单键当 B。页面内有按键校准，也支持电脑键盘。

## 使用

1. 下载整个仓库，双击 `index.html`，建议用 Chrome 打开。
2. 页面已预置实测键位：横握方向环、TV=A、菜单=B、Home=Start。若你的遥控器键码不同，点击「开始校准」重新设定。Select 暂未预置，可在校准时指定，或用键盘右 Shift。
3. 选择或拖入你自己的 `.nes` 文件。游戏文件只在本机读取，不会上传。

键盘备用键位：W A S D 方向，J=A，K=B，Enter=Start，右 Shift=Select。可暂停、重开、静音或全屏。

实测这款遥控器的蓝牙报告一次只有一个活动键。需要边走边跳或攻击时，勾选「方向锁定」，快速轻按同一个遥控器方向两次，松手后再按 TV 键或菜单键。按任一方向、暂停或切到其他窗口会解除锁定。也可以用遥控器控制方向，同时在电脑键盘上按 J 或 K。

遥控器按键只有在这个页面位于前台时才控制游戏。切到其他窗口会自动松开游戏按键，不修改 macOS 的全局键位。如果 TV 或菜单键按下后页面中的「最近收到」没有变化，说明该键未传到浏览器，需要检查遥控器连接或另外做设备级映射。

仓库不含商业游戏 ROM。模拟器使用 [JSNES 2.1.0](https://github.com/bfirsh/jsnes)，其 Apache-2.0 许可证见 [`vendor/LICENSE-jsnes.txt`](vendor/LICENSE-jsnes.txt)。
